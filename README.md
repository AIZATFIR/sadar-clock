# Sadar Clock (Awareness Interface)

> *"Stay vertical. Give each moment what it deserves."*

Sebuah antarmuka kesadaran waktu (*awareness interface*) minimalis & rendah beban kognitif (low cortisol), dirancang untuk menyelaraskan ritme kerja dan hidup dengan fitrah (kesadaran, hening, dan eksekusi bernilai).

## Esensi
Bukan sekadar penunjuk waktu digital atau *task tracker* yang membebani otak, melainkan cermin kognitif:
1. **Vertical Orientation:** Mengingatkan pada prioritas tertinggi dan arah hakiki.
2. **What Matters Now:** Menjawab satu pertanyaan esensial: apa fokus tunggal yang layak menerima perhatianmu saat ini?
3. **6 Siklus Fitrah:** Menjaga ritme hidup seimbang antara *Deep Work*, *Intentional Rest*, *Active Rest*, *Satisfying Reward*, *Wind Down*, dan *Sleep*.
4. **Stillness & Breathing Guide:** Pendamping ketenangan napas sadar di sela aktivitas.

## Tech Stack
- Pure Semantic HTML5, Modern CSS (Glassmorphism & Fluid Variables), Vanilla JS (Zero-dependency, high performance 60fps clockwork).
- Ringan, responsif, dan siap diakses langsung di desktop maupun mobile.
